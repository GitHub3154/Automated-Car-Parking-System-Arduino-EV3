Automated Car Parking System 

🥇 1st Place – Buds Public School - Ai week project 

An automated car parking system developed as a team project using Arduino, ultrasonic sensors, LEGO Mindstorms EV3, LEDs, and a buzzer.

The system uses ultrasonic sensors to detect the distance between the vehicle and nearby objects. Visual LED indicators and a buzzer provide warnings based on how close the vehicle is to an obstacle.
